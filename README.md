# vrcrp · 2.4

保留 https://erp.sex/ 的业务流程、主题、划卡逻辑、按钮次序、图标及动效，调整应用页面层级与 iOS 消息提醒。显示名 vrcrp，包名 `local.erp.stable`，最低 iOS 15。

## 页面与操作

- 底栏是 UIKit 实色控件。点击即在原生线程更新图标、文字与选中底色，无须等网页消息确认；网页完成导航后校准，失败或过期会撤销临时选择。按钮中心、尺寸、主题与原站一致。重复点击当前入口回到顶部，配对入口同时立即同步。
- 底栏只出现在主入口与探索/喜欢的同级视图。聊天、聊天进入的资料/世界详情、编辑、设置、通知和帖子详情都是独立页面；底栏隐藏，移除原有占位。逐级返回时保持隐藏，回到主入口才恢复。
- 键盘打开时隐藏底栏，聊天输入区使用实际原生视口高度。保留原来的键盘工具栏移除、缩放限制和编辑区选字粘贴。
- 探索卡片按可用高度适配，操作区与底栏留出间距。保留按钮顺序、触摸尺寸、原卡片拖动和动画；小屏幕空间不足时可以滚动，不缩小操作按钮。
- 仅增强卡片拖动时的原有喜欢/讨厌/超级喜欢印章：更早显示、实色背景、清晰边框和阴影。读取卡片实际位移，不阻止任何触摸，也不改变 Framer Motion 的方向、120 点判定、速度阈值和按钮行为。
- 顶栏使用网站表面色，状态栏取顶部当前显示色，避免页面黄色背景延伸到白色顶栏上方。浅色/深色文字跟随顶栏对比度，状态栏始终显示。
- 详情向右推进进入、向右退出返回。原生保存有容量上限的各历史页面截图，包含对应底栏；侧滑预览正确上一层并带视差、阴影及状态栏颜色过渡。松手往回滑可取消，取消不会改变历史、聊天和草稿；只有确认返回才切换原站路由，不重新加载文档。划卡主入口不抢返回手势，弹窗与输入键盘出现时暂停边缘返回。
- 恢复当前历史页及再次打开聊天时的滚动位置和未发送草稿。列表下拉刷新获取数据，避免重载整个网页。

## 聊天载入与同步

- 直接将服务器配对列表和未读数据写入原站已有的 TanStack Query 缓存，实时连接未建立或断开时仍更新页面。进行中/已结束均同步，保留分页，并在多页列表重新核对游标。
- 消息初始页和聊天资料采用账户、内容模式、语言隔离的内存缓存，最多 24 条、约 4 Mi 字符。资料 30 秒、消息 90 秒内可先显示已加载内容并后台校验；过期或被清理后正常获取。首屏最多预取 3 个会话，触摸会话时提前获取并合并相同在途请求；这些 GET 不发送消息或标记已读。
- 后台校验的真实新消息/撤回更新原站现有聊天事件处理器。网站当前版本已有 Query Provider 和事件总线可读取；仅调用其公开缓存/事件方法。检测不到兼容接口时回落原站事件/refetch，不修改站点源文件。
- 新消息、发送/已读完成、进入列表、回到前台和重新联网会马上补同步；正在同步时的新请求会保留，结束后再检查，不丢掉返回列表时的刷新。

## 配对消息

- 监听原站 `message.new` 事件，按聊天显示发送者/消息预览、声音和角标，图片、语音及 VRChat 链接使用类型提示。通知按聊天分组，点击或选择“打开聊天”可进入对应会话。
- 初次登录的旧消息、重复事件、自己的消息、正在前台阅读的会话不会产生重复提醒。退出或切换账号会清除提醒状态，并忽略旧账号的未完成请求及连接事件。
- 前台配对列表每 2 秒补同步、打开的聊天每 7 秒检查遗漏的消息/资料、其他页面每 10 秒补同步。实时更新继续保留。服务器限流/错误时退避，后台和不可见页面停止轮询。
- 请求不重叠，超时后结束，服务器限流或错误时退避。iOS 通知授权在登录后通过系统提示请求；网站通知设置页面新增“系统通知设置”入口，可管理系统声音、横幅和预览。
- 切到后台后使用系统允许的短时任务补同步，直接从网站读取未读数和最新会话。**长期后台、锁屏和关闭应用后的实时提醒不保证到达**。没有网站 APNs 服务及设备注册接口，当前无法达到微信/QQ 的持续后台推送。

## 数据

账号、Cookie 和接口仍属于原网站，无中转服务器。通知桥在设备本地传递必要的联系人、会话及预览字段；后台读取仅使用该网站的 WKWebView Cookie 与当前模式/语言。预览进入 iOS 通知系统，不上传到其他服务。预取/补同步不会发送消息或标记已读；当前聊天的已读行为仍由原站处理。缓存和草稿不新增磁盘存储；页面截图最多 8 张/40 MiB，并在切换账户、内容模式/语言和内存压力时清理。

使用相同签名覆盖安装可保留网站存储；卸载会删除登录数据。

## 编译与验证

```sh
bash scripts/build-unsigned.sh
```

GitHub Actions 使用 macOS/Xcode 构建未签名 arm64 IPA。模拟器验证键盘、底栏同步点击选中、原站导航位置、弹窗避让、聊天层级与三级页面、浅/深色状态栏、原生页面预览/跟手/取消/完成以及文档不重载。测试页通过模拟器本机 HTTP 加载，排除 `loadHTMLString` 不生成完整历史的问题。测试入口、虚构页面和研究文件不会进入真机 IPA。

浏览器用真正的 React 18/TanStack Query 和 Framer Motion 检查断线列表更新、缓存聊天/草稿/后台合并与三个方向的拖动提示、判定及取消。其他布局、键盘、路由与通知检查继续保留。

浏览器测试依赖 `scripts/browser-checks-package.json` 所列的开发包；安装到独立目录后设置 `TEST_NODE_MODULES` 指向其 `node_modules`，运行 `python3 scripts/test-chat-cache.py` 和 `python3 scripts/test-swipe-feedback.py`。需要 Python Playwright 和 Chromium（可通过 `CHROMIUM_PATH` 指定）。这些依赖只用于测试，不打进 IPA。

真实账号通知、签名后的 iOS 27 真机输入法、性能和后台运行仍需设备验证。API 首次获取、服务器限制、过期/内存清理后的载入仍受实际网络影响。
