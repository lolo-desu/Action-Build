# vrcrp · 2.8

保留 https://erp.sex/ 的业务流程、主题、划卡逻辑、按钮次序、图标及动效，调整应用页面层级与 iOS 消息提醒。显示名 vrcrp，包名 `local.erp.stable`，最低 iOS 15。

## 2.8 更新

- 返回预览持续覆盖真实网页，直到当前路由已绘制、WebKit 完成屏幕更新，再进行短交接。路由消息到达时不再提前撤走预览，避免上一层与退出页面来回闪烁。预览缓存也只在绘制后保存，防止缓存错误页面层级。
- 动画与绘制交接分开，不关闭网页触摸或等待加载才能返回；新的进入、返回和取消可以接替尚未交接完的预览。WebKit 持续可见，键盘与草稿处理延续 2.7。
- 下拉只保留顶栏下方的胶囊指示。通过原站支持的 `data-no-ptr` 停用网站 PWA 圆形刷新及其整页 reload，不阻挡页面触摸；移除多余系统刷新控件，刷新由应用原有原地同步处理。
- 聊天对方头像顶栏的表面铺满屏幕左右，保持内容区域的布局；输入区底部留白减少 6 点，保留系统安全区和键盘避让。
- 新增 iOS 模拟器录屏逐帧色块检查：列表→聊天→三级详情→聊天→列表，验证显示画面没有退出页面重新出现或误闪更上一层。浏览器检查全宽聊天栏与单刷新行为。

## 2.7 更新

- 导航动画不再关闭整页触摸，不等待接口、网页加载、截图或渲染帧才恢复操作。普通进入/退出使用可中断的短动画，新的页面跳转取消旧动画及过期回调；WebKit 始终保持可见，避免隐藏网页导致回调暂停。
- 首次进入、截图尚未完成或被内存清理时也能侧滑返回；截图仅增强上一层预览。历史路由先同步更新，再独立恢复滚动和草稿，不依赖动画帧确认返回。
- 连续返回按浏览器 popstate 顺序处理，不重复并发 history.back；返回尚未完成时点击的站内链接在恢复的页面继续执行。过期底栏模型、手势区域和页面恢复回调不再影响新页面。
- 聊天与编辑键盘展开/收起期间保留返回。滑动预览及取消保留输入焦点和键盘；确认返回才保存草稿并收起键盘。键盘通知不切断正在进行的手势，键盘动画允许触摸。
- 新增 Chromium/WebKit 浏览器快速切换验证，以及 iOS 模拟器冷页面立即返回、打断进入动画、键盘预览/取消/返回、连续多级返回、加载中返回和十次快速重进检查。

## 2.6 更新

- 外部网址、重定向及新窗口进入独立的 WebKit 浏览页，顶栏显示真实域名和页面标题，提供后退、前进、关闭；关闭保留应用原页面，回到 erp.sex 的登录回调交还主页面。

- 从聊天进入的他人名片保持逐级返回；探索中在当前页面展开的全屏名片也支持跟手预览、反向取消和关闭，调用原站关闭按钮，不刷新文档。
- 下拉刷新固定顶栏，禁用原先导致整页露出黄色的外层弹性滚动。顶栏下方显示原生高对比度提示与加载状态，刷新区沿用顶栏表面色。普通页面滚动、卡片和输入控件操作继续保留。
- 顶栏/状态栏颜色取当前顶栏表面色，减少滚动采样背景导致的意外变色；安装/加入主屏幕入口在应用内隐藏。

## 页面与操作

- 底栏是 UIKit 实色控件。按下即在原生线程统一更新图标、文字与选中底色，使用同一段短淡入淡出动画，无须等网页消息确认；颜色读取主题变量，避免读取网页颜色动画的中间值；网页完成导航后校准，失败或过期会撤销临时选择。按钮中心、尺寸、主题与原站一致。重复点击当前入口回到顶部，配对入口同时立即同步。
- 底栏只出现在主入口与探索/喜欢的同级视图。聊天、聊天进入的资料/世界详情、编辑、设置、通知和帖子详情都是独立页面；底栏隐藏，移除原有占位。逐级返回时保持隐藏，回到主入口才恢复。
- 键盘打开时隐藏底栏，聊天输入区使用实际原生视口高度；消息区域随之缩小，原本在底部阅读时保持最后一条可见，主动上翻历史时保留阅读位置。保留原来的键盘工具栏移除、缩放限制和编辑区选字粘贴。
- 探索卡片按可用高度适配，操作区与底栏留出间距。保留按钮顺序、触摸尺寸、原卡片拖动和动画；小屏幕空间不足时可以滚动，不缩小操作按钮。
- 仅增强卡片拖动时的原有喜欢/讨厌/超级喜欢印章：更早显示、实色背景、清晰边框和阴影。读取卡片实际位移，不阻止任何触摸，也不改变 Framer Motion 的方向、120 点判定、速度阈值和按钮行为。
- 顶栏使用网站表面色，状态栏取顶部当前显示色，避免页面黄色背景延伸到白色顶栏上方。浅色/深色文字跟随顶栏对比度，状态栏始终显示。
- 详情向右推进进入、向右退出返回。原生保存有容量上限的各历史页面截图，包含对应底栏；侧滑预览正确上一层并带视差、阴影及状态栏颜色过渡。松手往回滑可取消，取消不会改变历史、聊天和草稿；只有确认返回才切换原站路由，不重新加载文档。划卡主入口不抢返回手势，详情页支持从页面中间右滑，首段移动立即跟随手指；逐次检测当前可见的横向滚动区、卡片、滑块、输入及按钮，避免抢走这些操作。弹窗和选中文字时保留内容操作；聊天与编辑键盘打开时允许边缘及普通内容区返回，输入框本身仍优先处理编辑手势。
- 常看的通知、帖子、资料、世界等读取接口采用账户/模式/语言隔离的内存缓存，5 分钟内先显示已有内容并后台校验；相关修改和下拉刷新会清理对应缓存。再次进入历史详情可先显示已有页面截图，短动画结束后由真实界面接替，减少重复读条。
- 恢复当前历史页及再次打开聊天时的滚动位置和未发送草稿。列表下拉刷新获取数据，避免重载整个网页。

- 根入口切换、弹窗、新消息和普通按钮加入轻量动画，尊重系统“减弱动态效果”，保留原有划卡特效。
- 聊天文字、简介、资料卡和帖子内容允许长按选择与复制；划卡区域和操作控件保留手势限制。
- 待发送消息固定在已发送消息之后，修复手机与服务器时间不一致时排到顶部的问题。通过当前原站 React 消息状态的现有 setter 调整列表，保留消息对象、时间、内容和发送逻辑；接口结构改变时安全回退。


## 返回手势覆盖

按原站公开路由和当前渲染的控件判断，详情页默认允许从中间右滑；横向操作区在滚动、布局变化与开始触摸时重新检查，并按祖先滚动容器裁剪，避免已经滚走的控件继续挡住返回。

| 界面 | 返回与横向操作 |
| --- | --- |
| 探索、喜欢、配对、广场、我的主入口 | 使用底栏切换，保留划卡及同级入口操作 |
| 聊天、通知、访客与设置列表 | 有上一层时中间右滑返回，避开按钮、输入区和横向控件 |
| 帖子、公告与法律文本详情 | 正文区域中间右滑返回，横向代码块、图片操作保留 |
| 用户资料、世界详情、编辑与设置子页 | 空白和普通内容区可返回，避开相册、滑块、编辑框和操作按钮 |
| 图片、视频、画布、拖动控件与弹窗 | 保留内容操作；弹窗和选字期间保留其操作；键盘展开时正文/边缘可返回，输入区保留编辑操作 |
| 登录、注册及其他业务子页 | 主登录入口不返回；有上一层的子页采用同一规则，无截图也可返回 |

该判断作用于所有当前路由；新出现的横向滚动内容也按实际控件检测。首次进入、截图被内存清理或直接深链没有上一层时，原有返回按钮仍可用。需要真实账号才能进入的业务状态没有用测试账号冒充验证。

## 聊天载入与同步

- 直接将服务器配对列表和未读数据写入原站已有的 TanStack Query 缓存，实时连接未建立或断开时仍更新页面。进行中/已结束均同步，保留分页，并在多页列表重新核对游标。
- 消息初始页和聊天资料采用账户、内容模式、语言隔离的内存缓存，所有读取缓存合计最多 32 条、约 6 Mi 字符。资料 30 秒、消息 90 秒内可先显示已加载内容并后台校验；过期或被清理后正常获取。首屏最多预取 3 个会话，触摸会话时提前获取并合并相同在途请求；这些 GET 不发送消息或标记已读。
- 后台校验的真实新消息/撤回更新原站现有聊天事件处理器。网站当前版本已有 Query Provider 和事件总线可读取；仅调用其公开缓存/事件方法。检测不到兼容接口时回落原站事件/refetch，不修改站点源文件。
- 新消息、发送/已读完成、进入列表、回到前台和重新联网会马上补同步；正在同步时的新请求会保留，结束后再检查，不丢掉返回列表时的刷新。

## 配对消息

- 监听原站 `message.new` 事件，在 iOS 系统通知中显示昵称、ID、消息预览及头像缩略图，支持声音和角标，图片、语音及 VRChat 链接使用类型提示。头像仅使用网站允许公开显示的图片；隐藏/不可用或超时时使用昵称首字占位，头像请求不携带网站 Cookie。使用普通通知图片附件，避免增加通信通知签名权限；最终缩略图位置由 iOS 决定。通知按聊天分组，点击或选择“打开聊天”可进入对应会话。
- 初次登录的旧消息、重复事件、自己的消息、正在前台阅读的会话不会产生重复提醒。退出或切换账号会清除提醒状态，并忽略旧账号的未完成请求及连接事件。
- 前台配对列表每 2 秒补同步、打开的聊天每 7 秒检查遗漏的消息/资料、其他页面每 10 秒补同步。实时更新继续保留。服务器限流/错误时退避，后台和不可见页面停止轮询。
- 请求不重叠，超时后结束，服务器限流或错误时退避。iOS 通知授权在登录后通过系统提示请求；网站通知设置页面新增“系统通知设置”入口，可管理系统声音、横幅和预览。
- 切到后台后使用系统允许的短时任务补同步，直接从网站读取未读数和最新会话。**长期后台、锁屏和关闭应用后的实时提醒不保证到达**。没有网站 APNs 服务及设备注册接口，当前无法达到微信/QQ 的持续后台推送。

## 数据

账号、Cookie 和接口仍属于原网站，无中转服务器。通知桥在设备本地传递必要的联系人、会话及预览字段；后台读取仅使用该网站的 WKWebView Cookie 与当前模式/语言。预览进入 iOS 通知系统，不上传到其他服务。预取/补同步不会发送消息或标记已读；当前聊天的已读行为仍由原站处理。缓存和草稿不新增磁盘存储；页面截图最多 12 张/60 MiB，并在切换账户、内容模式/语言和内存压力时清理。

使用相同签名覆盖安装可保留网站存储；卸载会删除登录数据。

## 编译与验证

```sh
bash scripts/build-unsigned.sh
```

GitHub Actions 使用 macOS/Xcode 构建未签名 arm64 IPA。模拟器按页面、动画和外链加载就绪状态依次检查，避免用固定延时判断异步结果；验证键盘弹出后最后一条消息可见、通知头像附件/ID/内容、底栏按下及网页颜色过渡中同步选中、原站导航位置、弹窗避让、聊天层级与三级页面、浅/深色状态栏、原生页面预览/从页面中间返回/跟手/取消/完成以及文档不重载。测试页通过模拟器本机 HTTP 加载，排除 `loadHTMLString` 不生成完整历史的问题。同时检查名片编辑返回/标签同层历史、聊天顶栏与未读数、全屏名片预览取消、外链顶栏/后退/前进/关闭以及浅深色下拉区与状态栏颜色。测试入口、虚构页面和研究文件不会进入真机 IPA。

浏览器用真正的 React 18/TanStack Query 和 Framer Motion 检查断线列表更新、缓存聊天/草稿/后台合并与三个方向的拖动提示、判定及取消。同时检查待发送消息排序、通知列表缓存、内容复制与横向手势区域避让。其他布局、键盘、路由与通知检查继续保留。

浏览器测试依赖 `scripts/browser-checks-package.json` 所列的开发包；安装到独立目录后设置 `TEST_NODE_MODULES` 指向其 `node_modules`，运行 `python3 scripts/test-chat-cache.py` 和 `python3 scripts/test-swipe-feedback.py`。需要 Python Playwright 和 Chromium（可通过 `CHROMIUM_PATH` 指定）。这些依赖只用于测试，不打进 IPA。

真实账号通知、签名后的 iOS 27 真机输入法、性能和后台运行仍需设备验证。API 首次获取、服务器限制、过期/内存清理后的载入仍受实际网络影响。
