# vrcrp · 2.2 Liquid Glass

保留 https://erp.sex/ 的划卡逻辑、内容布局、按钮排布、图标、语言、主题色和动画，加入 iOS 外层体验。内容继续由原网站提供；底部导航由 UIKit 实现。

## 界面与操作

- iOS 26+ 底部导航使用真正的 `UIGlassEffect`，五个入口的图标来自网站当前 SVG；文字、选中颜色、角标及按钮中心位置来自网站的实际布局。点击通过网站原有链接处理，不重做登录或业务接口。
- 原网页导航保留布局占位，但在原生导航接管后隐藏显示和辅助功能。遇到网站弹窗、菜单遮罩、图片预览时，原生导航避让；无法解析导航时回退到网页导航。
- 顶栏和网站弹层增加玻璃风格的透明、模糊、边缘高光与阴影；保留原有配色、尺寸、文字及内部按钮。内容卡片沿用网站设计。
- 点击导航、按钮及成功划卡有轻微系统触感；成功发送消息使用系统反馈。失败发送不会触发成功反馈，不读取消息正文。
- 增加短页面转场、详情页边缘返回；探索划卡及其他根页面不开启边缘返回。网站弹窗或键盘打开时也暂停边缘返回。
- 列表页面提供原生下拉刷新，启动和首次连接失败使用原生界面；记录最后使用的主入口及主题色。
- 普通站外链接使用 iOS 内置浏览器弹层，身份认证链接和重定向保留原登录流程。
- 保留页面缩放抑制、编辑区选字粘贴、键盘工具栏移除、原生键盘高度同步、极简黑白图标和可见状态栏。
- 支持系统减少动态效果和降低透明度设置；iOS 15–25 导航使用系统材质回退。

## 验证与编译

浏览器检查字体、按钮几何和前景配色、原 SVG 图标、导航原有点击处理、角标、详情返回、划卡入口不抢返回手势、弹窗避让、发送结果反馈和辅助功能；另检查通知和键盘布局。

GitHub Actions 在 macOS 26/Xcode 上构建 unsigned arm64 IPA；模拟器另外编译测试专用应用，验证首次及再次呼出键盘、输入框可见、不缩放、工具栏移除、实际系统 Liquid Glass、原生导航点击与位置以及弹窗避让。测试入口和虚构页面不会进入真机 IPA。

```sh
bash scripts/build-unsigned.sh
```

产物 `build/ERPStable-unsigned.ipa`。最低 iOS 15；Liquid Glass 需要 iOS 26+，适用于用户的 iOS 27。未签名 IPA 需自行签名安装。

实际账号的登录、划卡、上传、输入法及 iOS 27 真机效果仍需用户设备验证。网站更新会反映到应用里，导航集成也可能随网站结构变化需要调整。

## 数据与提醒

登录、Cookie、接口及网页历史直接由原网站和持久化 WKWebView 处理，没有自定义中转服务器。导航桥只传导航信息和通用反馈，不传请求或响应正文。返回预览只保留在内存中，不保存聊天截图到磁盘。

包名仍为 `local.erp.stable`。使用相同包名和签名覆盖安装可保留容器中的登录及网页历史；卸载会删除它们。2.0 原生预览版的消息缓存不会自动导入网站存储。

可选本地聊天提醒延续原有实现，需要网页仍在运行。尚无 APNs 服务，后台、锁屏或终止应用后的提醒不保证到达。
