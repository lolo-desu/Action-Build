# vrcrp · 2.1 网站界面版

面向 https://erp.sex/ 的第三方 iOS 应用。主界面直接运行网站的当前页面、样式和 JavaScript；没有 SwiftUI 重绘页面，也没有自定义原生标签栏。划卡、按钮、动画、主题、聊天、资料、广场及设置由原网站实现。

最低 iOS 15，arm64 真机；使用当前 Xcode/iPhoneOS SDK 编译。应用名为 vrcrp，保留极简黑白图标及可见的顶部状态栏。

## 容器做了什么

- 固定网页 viewport 并关闭 WKWebView 页面缩放，抑制双击及输入框聚焦时的缩放。
- 关闭容器左右滑动返回和链接预览，避免与网站的划卡及长按操作冲突；保留网站自身导航和手势事件。
- 非编辑区域禁止系统文字选择及长按菜单；编辑区保留选字、复制和粘贴。不拦截网站的 pointer/touch/click 事件。
- 保留网站原有字号、按钮尺寸、顶栏间距、主题、CSS 动画、焦点逻辑和划卡代码。
- 只在聊天页面补充实际可用高度，按系统键盘最终位置调整 WKWebView 底边，解决过期 dvh 引起的输入框遮挡。其他页面不覆盖网站的高度规则。
- 提前去掉 WebKit 的上一项、下一项和 Done 键盘工具栏，不在键盘显示期间调用 reloadInputViews。
- 持久化保存网站 Cookie 和网页本地数据，直接连接网站，不使用自定义中转服务器。
- 为网站拍照、选照片和语音功能提供系统权限说明。
- 可选 iOS 本地聊天提醒；监听网站已有的未读计数，不附带聊天正文。

## 编译

GitHub Actions 分支 `vrcrp-web-ios` 使用 macOS 26 runner 构建。

```sh
bash scripts/build-unsigned.sh
```

产物 `build/ERPStable-unsigned.ipa` 不含开发者签名和描述文件；使用自己的侧载工具签名安装。模拟器测试构建中的测试页面和验证入口不包含在真机 IPA 中。

## 验证

- 浏览器验证：容器注入前后的字号、间距、按钮及布局一致；首次键盘高度变化、收起/重开、多行输入、过期 dvh、无效高度、离开聊天后的原有页面高度。
- 通知验证：首次未读计数不提醒、计数增加、重复计数、读取归零、重连、无效事件、来源隔离。
- CI：编译真机 arm64 应用，检查 IPA 压缩包、资源及无签名状态；另编译测试专用模拟器应用，实际呼出/收起/重新呼出 WebKit 键盘，读取网页与原生视口几何并检查输入框可见、工具栏已移除；保存原网站登录页截图。

仍需用户设备验证 iOS 27 的具体输入法、横竖屏以及已登录账号的划卡和聊天。网站内容和权限由原服务器决定，网站更新也会直接反映到应用中。

## 更新及提醒限制

保留原来的包名 `local.erp.stable`。使用相同签名身份及包名覆盖安装可保留应用容器里的网站登录和本地历史；卸载会删除这些数据。2.0 原生预览版的原生消息缓存保留在容器中，但本版本不会自动把它导入网站历史；旧网页版本保存的历史仍由网站自己的存储管理。

本地聊天提醒依赖网页仍在运行。本版本没有 APNs 后台服务，不能保证后台、锁屏或终止应用后收到通知。网站已有 Web Push 不能直接提供给这个 WKWebView 容器。
